# Документация по агрегированным пользовательским признакам

Датасет содержит агрегированные признаки поведения пользователей на основе их транзакций.

- **Количество пользователей:** ~1.2 млн  
- **Количество признаков:** 98  
- **1 строка = 1 пользователь**

---

# 1. Идентификатор

### party_rk

Уникальный идентификатор пользователя.

Тип: `string`

Используется только для идентификации и join-ов.  
В модель не подается.

---

# 2. Метрики активности

Описывают **общую активность пользователя**.

### txn_cnt

Общее число транзакций пользователя.

```
txn_cnt = количество транзакций
```

---

### unique_transaction_cnt

Количество **уникальных транзакций** (без дублей).

```
unique_transaction_cnt = count(distinct transaction_id)
```

---

### active_days_cnt

Количество дней, когда у пользователя была хотя бы одна транзакция.

```
active_days_cnt = count(distinct transaction_date)
```

---

### active_weeks_cnt

Количество недель с активностью.

```
active_weeks_cnt = count(distinct transaction_week)
```

---

### active_months_cnt

Количество месяцев с активностью.

```
active_months_cnt = count(distinct transaction_month)
```

---

### first_txn_dttm

Дата первой транзакции пользователя.

---

### last_txn_dttm

Дата последней транзакции пользователя.

---

### activity_span_days

Разница между первой и последней транзакцией.

```
activity_span_days = last_txn_dttm − first_txn_dttm
```

Показывает, как долго пользователь активен.

---

# 3. Интенсивность активности

Показывает **насколько часто пользователь делает операции**.

---

### avg_txn_per_active_day

Среднее число транзакций в активный день.

```
avg_txn_per_active_day = txn_cnt / active_days_cnt
```

---

### avg_txn_per_week_active

Среднее число транзакций в активную неделю.

```
avg_txn_per_week_active = txn_cnt / active_weeks_cnt
```

---

### avg_txn_per_month_active

Среднее число транзакций в активный месяц.

```
avg_txn_per_month_active = txn_cnt / active_months_cnt
```

---

# 4. Временной профиль поведения

Описывает **когда пользователь чаще всего совершает транзакции**.

---

### dominant_hour

Час суток, когда пользователь чаще всего делает транзакции.

```
0–23
```

---

### dominant_weekday_num

День недели, когда чаще всего происходят транзакции.

Обычно:

```
0 = понедельник
...
6 = воскресенье
```

---

# 5. Распределение транзакций по времени суток

Доли транзакций в разных периодах дня.

Значения находятся в диапазоне:

```
0 – 1
```

---

### share_night_txn

Доля ночных транзакций.

```
00:00 – 06:00
```

---

### share_morning_txn

Доля утренних транзакций.

```
06:00 – 12:00
```

---

### share_afternoon_txn

Доля дневных транзакций.

```
12:00 – 18:00
```

---

### share_evening_txn

Доля вечерних транзакций.

```
18:00 – 24:00
```

---

# 6. Будни vs выходные

---

### share_weekend_txn

Доля транзакций на выходных.

```
share_weekend_txn = weekend_txn / txn_cnt
```

---

### share_weekday_txn

Доля транзакций в будние дни.

```
share_weekday_txn = weekday_txn / txn_cnt
```

Обычно:

```
share_weekend_txn + share_weekday_txn ≈ 1
```

# 7. Поведение по категориям

Описывает **на что пользователь тратит деньги**.

---

### unique_category_cnt

Количество различных категорий трат.

```
unique_category_cnt = count(distinct category)
```

---

### top_category_txn_share

Доля самой популярной категории.

```
top_category_txn_share = max(category_txn_cnt) / txn_cnt
```

Интерпретация:

- высокое значение → пользователь тратит в основном в одной категории
- низкое → распределенные траты

---

### category_entropy

Энтропия распределения категорий.

```
category_entropy = − Σ p_i log(p_i)
```

где

```
p_i = доля категории i
```

Интерпретация:

- низкая → траты сосредоточены
- высокая → разнообразные траты

---

### cat_share_*

Колонки вида:

```
cat_share_*
```

Показывают долю транзакций в конкретной категории.

Пример:

```
cat_share_supermarkets
cat_share_transport
cat_share_fast_food
```

Формула:

```
cat_share_X = транзакции категории X / txn_cnt
```

---

# 8. Поведение по MCC

MCC — Merchant Category Code  
Стандартная банковская классификация типа бизнеса.

---

### unique_mcc_cnt

Количество различных MCC кодов.

```
unique_mcc_cnt = count(distinct mcc_code)
```

---

### top_mcc_txn_share

Доля самого частого MCC.

```
top_mcc_txn_share = max(mcc_txn_cnt) / txn_cnt
```

---

### mcc_entropy

Энтропия распределения MCC.

```
mcc_entropy = − Σ p_i log(p_i)
```

---

### mcc_share_*

Колонки вида:

```
mcc_share_XXXX
```

где `XXXX` — MCC код.

Показывают долю транзакций данного типа.

```
mcc_share_XXXX = транзакции с MCC XXXX / txn_cnt
```

---

# 9. Метрики разнообразия поведения

---

### category_diversity_ratio

Отношение числа категорий к общему числу транзакций.

```
category_diversity_ratio =
unique_category_cnt / txn_cnt
```

Показывает насколько пользователь распределяет траты.

---

### mcc_diversity_ratio

Аналогичная метрика для MCC.

```
mcc_diversity_ratio =
unique_mcc_cnt / txn_cnt
```

---

# Итог

Признаки описывают 4 аспекта поведения пользователя:

1. **Активность**  
   сколько операций делает пользователь

2. **Интенсивность**  
   как часто он делает транзакции

3. **Временной профиль**  
   когда он активен

4. **Поведенческий профиль**  
   где и на что он тратит деньги

Эти признаки используются для:

- построения **user embeddings**
- поиска **похожих пользователей**
- кластеризации пользователей
- рекомендационных систем
- анализа поведенческих сегментов
